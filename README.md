## 项目结构

```
finance-daily/
├── README.md          ← 本文件（目录索引入口）
├── AGENTS.md           # AI 任务入口说明
├── docs/               # 每日快讯 md 源稿（网页可读）
├── archives/           # HTML + DOCX 归档（按日期分目录）
├── SDD/                # 项目规格文档（Constitution/Spec/Plan/Tasks）
├── 台账/               # 预测台账（预测记录+回测）
├── 知识库/              # 搜索源配置 + 术语题库
└── 模板/               # HTML 渲染模板
```

## 使用方式

1. **阅读今日快讯** → 点击索引中对应日期的 md 链接（GitHub 网页直接渲染）
2. **查看详细信源** → 打开 HTML 版（带完整信源链接和配色）
3. **回溯历史预测** → 台账/预测台账.md 查看命中率统计
4. **新增一期** → 在 `docs/` 放 `YYYY-MM-DD.md`，归档入 `archives/YYYY-MM-DD/`，更新本索引表

## 质量红线

- 所有数值必须联网验证（禁止凭记忆输出）
- 数据来源分级：官方源 > 专业平台 > 权威媒体 > 自媒体（禁止后者）
- 预测必须登记台账，禁止输出未登记的方向性断言
- 详见 [SDD/01-Constitution.md](SDD/01-Constitution.md)
