# 金融日报 SDD · 06-QuickStart 预检清单

> 版本：v1.0 ｜ 生效日期：2026-08-25 ｜ 归属：finance-digest 技能
> 本文件是**每日日报生成前的30秒预检**，用于判断当天搜索策略，跳过无效搜索，节省Token。

---

## 用法

每次生成日报前，先回答下面6个问题。根据回答结果选择执行模式（全量/精简/降级），再进入SDD 03-Plan的C1采集合同。

---

## 0. 日期预判（6问30秒）

| # | 问题 | 判断方式 | 影响 |
|---|------|---------|------|
| Q1 | 今天是A股交易日吗？ | 周一至周五且非法定假日 → 是 | 否→A类信号用最近交易日，T2搜索降级为month |
| Q2 | 今天是LPR报价日吗？ | 每月20日（遇假日顺延）→ 是 | 是→T4升为头条级，强制T10交叉验证 |
| Q3 | 本周有宏观数据发布吗？ | CPI/PPI(每月9-10日)、PMI(月末/月初)、社融(每月10-15日) | 是→T7升为高优先级，标注统计区间 |
| Q4 | 本周有美联储事件吗？ | FOMC议息(每年8次)、CPI(每月13日左右)、非农(每月第一个周五) | 是→T6升为高优先级，概率数据强制标"预测值" |
| Q5 | 昨夜国际市场有大事吗？ | 油价暴涨/暴跌、地缘冲突、美股大跌(>2%) | 是→T5升为高优先级，追加1轮大宗搜索 |
| Q6 | 今天是周末/法定假日吗？ | 周六日、春节/国庆等 | 是→A类全降级，B/D类正常，整体可走精简模式 |

## 1. 执行模式选择

根据Q1-Q6回答结果，选择执行模式：

### 全量模式（默认）

**触发条件**：Q1=是（交易日），无其他特殊情况

**执行**：
- 8组搜索全跑（R1-R4，每轮2个并发）
- T10头条交叉验证
- 11信号5字段完整输出
- HTML + docx双格式交付
- 预计Token：~20K

### 精简模式

**触发条件**：Q1=否（非交易日）或 Q6=是（周末/假日）

**执行**：
- 跳过T2 A股核心组（用最近交易日数据，标"截至X月X日收盘"）
- 跳过T8 资金面组（非交易日无数据）
- 保留T3-T7、T9（汇率/利率/大宗/海外/宏观/政策）
- T5/T6如Q5/Q4有事件则正常跑
- 7-8信号输出（A股/资金面用前值+标注）
- HTML + docx双格式
- 预计Token：~14K（节省约30%）

### 事件模式

**触发条件**：Q2=是（LPR日）或 Q3=是（宏观数据发布）或 Q4=是（美联储事件）或 Q5=是（国际大事）

**执行**：
- 8组搜索全跑
- **事件信号升为头条级**，强制T10独立交叉验证（用不同关键词二次搜索）
- 事件信号追加1轮专项搜索（如LPR→搜"LPR报价结果 X月X日"）
- 11信号5字段完整输出
- 在"今日要点"中置顶事件信号
- HTML + docx双格式
- 预计Token：~24K（事件验证多花~4K）

### 降级模式

**触发条件**：搜索结果<3条 或 工具连续失败

**执行**：
- 按SDD 01-Constitution §6降级策略执行
- 输出简版日报，明示"今日信息较少"
- 标注降级原因
